# Review

Use the focused review skills instead of carrying both workflows here.

- For a GitHub PR number or URL, use `review-pr`.
- For a local branch, current checkout, staged/unstaged changes, or review since a ref, use `review-current`.

If this skill is loaded alongside either focused skill, follow the focused skill. If only this skill is loaded, choose the matching workflow above and proceed.
